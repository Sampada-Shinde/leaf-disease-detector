# Leaf Disease Detector

A Spring Boot REST API where a user uploads a leaf image. The image is saved in a folder and its details are saved in MySQL.

## Technologies
- Java
- Spring Boot
- MySQL
- Maven

## APIs
- POST /api/leaf-images/upload : upload a leaf image
- GET /api/leaf-images : get all images
- GET /api/leaf-images/{id} : get one image by id
